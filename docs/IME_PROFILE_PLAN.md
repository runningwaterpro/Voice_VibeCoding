# Input-method setup boundary

The RC003 product does not ship executable input-method presets. It sends the user's configured generic hotkey and transports microphone audio.

The user configures the external input method separately:

1. Choose an arbitrary voice-button mapping in the RC003 app.
2. Configure the same hotkey as a hold-to-talk shortcut in the external input method.
3. Select `CABLE Output` in that input method.
4. Hold the RC003 voice button to talk; release to stop.

Doubao and Qianwen are real-device acceptance cases, not runtime modes. There is no built-in WeChat, Doubao, Qianwen, toggle, or hands-free preset.
